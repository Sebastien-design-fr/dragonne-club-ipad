# Dragonne Club – version iPad

Copie web de l'appli Dragonne Club, publiée sur GitHub Pages pour l'iPad.
Sur l'iPad : ouvrir l'adresse dans Safari, puis Partager > Sur l'écran d'accueil.
La version Android (APK) reste dans le dépôt dragonne-club et n'est pas concernée.
Les données (ventes, articles) restent sur l'iPad ; sauvegarde via la tuile « Sauvegarde ».
